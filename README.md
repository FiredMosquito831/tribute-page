## What this project is

A responsive, accessible page built with semantic HTML5 and modern CSS, written to satisfy the user stories set by
freeCodeCamp for this certification project. It is part of the Responsive Web Design v9 curriculum,
whose certification requires completing all coursework plus this set of certification projects
and passing the certification exam.

- **Curriculum:** freeCodeCamp Responsive Web Design (v9)
- **Project type:** Certification project
- **Tech stack:** HTML5, CSS3
- **Challenge page:** <https://www.freecodecamp.org/learn/responsive-web-design-v9/lab-tribute-page/lab-tribute-page>

## Project files

- `index.html` — page markup and structure
- `styles.css` — styles and layout

## How to run

Open `index.html` in any modern browser — no build step, no dependencies.

```bash
# optional: serve locally
npx serve .
```
